# Minecraft Mod: MascotasBiome

MascotasBiome is a Minecraft Bedrock addon that adds a wide variety of domesticable pet animals, each spawning in their natural biomes. From dogs and cats in the plains to birds and parrots in the jungle, small mammals in the savanna, and reptiles in the desert, all creatures can be tamed and will follow you once domesticated. The mod adds dozens of visual variants for each pet type, including different dog breeds, cat breeds, parrot species, hamsters, rabbits, and more, all with realistic behaviors like flying, climbing, and following.

## Install

1. Download the MascotasBiome .mcaddon file from the latest release.
2. Open the file with Minecraft Bedrock Edition on your device (Windows, Android, iOS, or console with file sharing support).
3. The addon will automatically import into Minecraft.
4. Activate the addon in your world settings under "Behavior Packs" (and "Resource Packs" if included).
5. Create a new world or edit an existing one, ensuring the MascotasBiome pack is applied.

## Use

1. Explore the specified biomes to find pets:
   - Plains: dogs, cats, and various small mammals.
   - Jungle: birds, parrots, and other avian species.
   - Savanna: small mammals like hamsters, ferrets, rabbits, guinea pigs, and chinchillas.
   - Desert and Mesa: reptiles like geckos.
2. Tame animals using their specific food items:
   - Dogs, cats, birds, parrots, and most mammals use seeds, fish, carrots, or apples.
   - Geckos are tamed with beetroot or carrots.
3. Once tamed, pets will follow you around and can be leashed.
4. Cats will repel creepers, and geckos can climb walls.
5. Use names on animals to personalize them.
